# مدينة النخبة - نسخة البداية

نسخة أولية قابلة للتشغيل محلياً: مدينة ثلاثية الأبعاد، حسابات، حركة WASD، مزامنة مواقع اللاعبين، دردشة عامة، محفظة، وظيفة تجريبية، وتصويت للعمدة.

## المتطلبات
- Node.js 20 أو أحدث
- اتصال إنترنت لتحميل مكتبة Three.js والخط من CDN

## التشغيل
1. فك ضغط المشروع.
2. افتح الطرفية داخل مجلد المشروع.
3. نفّذ:
   ```bash
   npm install
   npm start
   ```
4. افتح `http://localhost:3000` في المتصفح.
5. أنشئ حسابين من نافذتين أو جهازين لاختبار تعدد اللاعبين.

## إعداد مدير الخادم
قبل التشغيل، عيّن اسم مستخدم موجود كمدير:
- Windows PowerShell: `$env:ADMIN_USERNAME="اسم_الحساب"; npm start`
- macOS/Linux: `ADMIN_USERNAME="اسم_الحساب" npm start`

## الموجود حالياً
- عالم 3D أولي مع مبانٍ وشوارع وحديقة ومبنى بلدية.
- تسجيل حساب وتسجيل دخول بكلمات مرور مجزأة باستخدام bcrypt.
- تحريك الشخصية ومزامنة اللاعبين عبر Socket.IO.
- دردشة عامة.
- محفظة وعمل تجريبي بمكافأة ثابتة.
- تصويت تجريبي للعمدة. إغلاق الانتخابات محصور بحساب المدير.

## مهم قبل النشر العام
هذه نسخة تأسيسية وليست جاهزة لاستقبال جمهور حقيقي:
- الجلسات حالياً تستخدم مخزن Express الافتراضي داخل الذاكرة؛ استبدله بمخزن جلسات دائم.
- أضف HTTPS، وحدوداً لمحاولات الدخول والرسائل، والتحقق من المدخلات ومكافحة الإساءة.
- أضف نظام حفظ مواقع اللاعبين، ومباني قابلة للشراء، ومخزوناً واقتصاداً متوازناً.
- أضف صلاحيات حكومية دقيقة وسجل قرارات وشفافية للانتخابات.
- لا تضع أسرار الإنتاج في الكود. عيّن `SESSION_SECRET` عشوائياً وقوياً.
- قاعدة البيانات `city.sqlite` تُنشأ تلقائياً بجانب `server.js`.

## ملاحظات
هذه اللعبة ليست مستضافة على الإنترنت تلقائياً. لتجميع لاعبين من أماكن مختلفة، ارفع الخادم إلى خدمة استضافة تدعم Node.js وWebSocket، واربطه بقاعدة بيانات دائمة.
